AUTOMATION WITH GITHUB ACTIONS
------------------------------

Weekly ScienceDaily Parsing (.github/workflows/weekly-digest.yml):

name: Weekly ScienceDaily Digest
on:
  schedule:
    - cron: '0 9 * * 1'  # Every Monday 9:00 UTC
  workflow_dispatch:  # Manual trigger

jobs:
  parse-sciencedaily:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '18'
      
      - name: Install dependencies
        run: npm install axios cheerio
      
      - name: Run ScienceDaily parser
        run: node Scripts/parse-sciencedaily.js
      
      - name: Run arXiv sync
        run: node Scripts/sync-arxiv.js
      
      - name: Generate startup data
        run: node Scripts/generate-startups.js
      
      - name: Commit changes
        run: |
          git config --local user.email "action@github.com"
          git config --local user.name "GitHub Action"
          git add data/
          git commit -m "Auto-update: Weekly digest $(date +%Y-%m-%d)" || echo "No changes"
          git push


CLOUDFLARE WORKER BACKEND SETUP
-------------------------------

For comment system and advanced features:

1. Create Worker at https://dash.cloudflare.com
2. Use this basic structure:

// worker/index.js
export default {
  async fetch(request, env) {
    const url = new URL(request.url);
    
    // CORS headers
    const corsHeaders = {
      'Access-Control-Allow-Origin': '*',
      'Access-Control-Allow-Methods': 'GET, POST, OPTIONS',
      'Access-Control-Allow-Headers': 'Content-Type',
    };
    
    // Handle preflight
    if (request.method === 'OPTIONS') {
      return new Response(null, { headers: corsHeaders });
    }
    
    // Comments endpoint
    if (url.pathname === '/api/comments' && request.method === 'POST') {
      const data = await request.json();
      // Save to KV storage
      await env.COMMENTS.put(
        `${data.paperId}:${Date.now()}`,
        JSON.stringify(data)
      );
      return Response.json({ success: true }, { headers: corsHeaders });
    }
    
    // Get comments
    if (url.pathname === '/api/comments' && request.method === 'GET') {
      const paperId = url.searchParams.get('paperId');
      const list = await env.COMMENTS.list({ prefix: paperId });
      return Response.json(list.keys, { headers: corsHeaders });
    }
    
    return new Response('Not Found', { status: 404 });
  }
};

3. Deploy with Wrangler CLI:
   npm install -g wrangler
   wrangler login
   wrangler deploy

TROUBLESHOOTING
---------------

Issue: Changes not showing on GitHub Pages
Solution:
- Check if pushed to main branch
- Verify Pages settings (Source: main branch)
- Wait 1-2 minutes for deployment
- Clear browser cache (Ctrl+Shift+R)

Issue: 404 errors on subpages
Solution:
- Verify file paths are correct (case-sensitive)
- Check .gitignore isn't excluding files
- Ensure all HTML files are committed

Issue: OAuth not working
Solution:
- Configure OAuth credentials in provider dashboard
- Update redirect URI to match GitHub Pages URL
- Check browser console for error messages

Issue: Styles not loading correctly
Solution:
- Check CSS paths are relative
- Verify assets folder is deployed
- Inspect network tab for 404s on CSS files


PERFORMANCE OPTIMIZATION
------------------------

Current Bundle Size: ~200KB (HTML + CSS + JS)

Optimization Tips:
1. Minify CSS and JavaScript
2. Compress images (use WebP format)
3. Enable gzip/brotli compression (automatic on GitHub Pages)
4. Use lazy loading for images below fold
5. Consider splitting CSS into critical + non-critical
