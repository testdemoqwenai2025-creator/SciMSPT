## 🆘 Troubleshooting Common Issues

### Issue: "quantum.html not found in browser"
**Solution:** Use full path: `file:///home/z/my-project/SciMSPT/quantum.html`
Or start local server: `cd /home/z/my-project/SciMSPT && python3 -m http.server 8080`

### Issue: "Navigation links broken"
**Solution:** Verify you're opening from `SciMSPT/` directory, not individual files. Relative paths require correct base.

### Issue: "Investor letter formatting broken"
**Solution:** Open in Markdown viewer (VS Code, Typora) or convert to PDF using Pandoc:
```bash
pandoc CUSTOMIZED_INVESTOR_LETTERS.md -o investor_letters.pdf
```

### Issue: "Git push rejected"
**Solution:** Pull latest changes first:
```bash
cd /home/z/my-project/SciMSPT
git pull origin main
# Resolve any conflicts, then:
git push origin main
```

### Issue: "DemoSciMSPT not updating"
**Solution:** DemoSciMSPT is a separate repo. Copy files manually:
```bash
cp /home/z/my-project/SciMSPT/quantum.html /home/z/my-project/DemoSciMSPT/quantum.html
cd /home/z/my-project/DemoSciMSPT
git add quantum.html
git commit -m "Update quantum page"
git push origin main
```
